As part of the course ES-335 (Machine Learning) assignment, we collected raw accelerometer data from six individuals performing various activities, including walking upstairs, walking downstairs, running, standing, sitting, and sleeping. The data was recorded using the Physics Toolbox Sensor app.

We preprocessed and cleaned the data, engineered a few additional features, and also used the tsfel library to extract specialized time-series features. A Random Forest classifier was then trained on this dataset, achieving an accuracy of approximately 60%.
